# Ayyanar Gold Bank

Static bilingual Tamil/English website files for GitHub.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive layout and styling
- `app.js` — calculator, Tamil/English switch, FAQ chatbot, and live-rate display
- `assets/` — supplied logo and Managing Director photo

Upload these files and the `assets` folder to the root of your GitHub repository. The page uses relative asset paths, so keep the folder structure unchanged. If you enable GitHub Pages, configure it to serve the repository root.

The live ticker fetches indicative gold and silver spot prices from Gold API. It derives a 916 reference from the 24K spot price; the branch appraisal remains the final pledge quote. The chatbot uses the page's built-in Ayyanar Gold Bank facts and does not use Vapi. Browser speech depends on device/browser support.
